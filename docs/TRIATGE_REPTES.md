# Escollir el repte — matriu per als primers 20 minuts

**Aquesta fitxa és genèrica i no conté cap solució.** No puntueu fins que els organitzadors hagin presentat els tres reptes.

## Mètode

Cadascú avalua independentment els tres reptes de l'1 (dolent) al 5 (molt bo). Després compareu i justifiqueu les diferències amb dades de l'enunciat, no intuïcions sense evidència.

| Criteri | Pes | Què cal buscar? |
|---|---:|---|
| Claredat de dades i objectiu | 25 % | Dataset accessible, definicions precises i criteris de validació clars |
| Probabilitat d'obtenir una baseline completa | 25 % | Primera solució comprovable amb les hores disponibles |
| Potencial diferencial / innovació | 20 % | Millora demostrable, bona idea i aportació tècnica distintiva |
| Demo clara i impacte | 15 % | Resultat fàcil d'explicar i mostrar als jutges |
| Encaix amb les habilitats de l'equip | 15 % | Les quatre persones poden treballar en paral·lel amb poc bloqueig |

**Puntuació ponderada** = 0,25·Dades + 0,25·Baseline + 0,20·Diferencial + 0,15·Demo + 0,15·Equip. Rang d'1 a 5.

## Preguntes eliminatòries abans d'escollir

1. Sabem amb exactitud què s'ha d'entregar i quan?
2. Tenim accés immediat a les dades o a la documentació necessària?
3. La mètrica d'èxit és mesurable sense fer trampes metodològiques?
4. Podem construir alguna cosa end-to-end abans de dedicar-nos a optimitzar?
5. Hi ha restriccions de dades, IA, internet o hardware que invalidin l'enfocament?
6. Si fallen els models avançats, tindrem una demo creïble amb la baseline?

## Després d'escollir

- Registreu la decisió a `docs/DECISIONS.md`, indicant el perquè.
- Ompliu `docs/BRIEF.md` amb l'enunciat exacte.
- Assigneu 4 tasques reals i les branques corresponents a `docs/STATUS.md`.
- Acordeu un primer checkpoint d'integració i una única mètrica principal.
- Si la informació és incompleta, pregunteu a l'organització abans de desenvolupar.

**Nota:** guanyar no depèn únicament de maximitzar una mètrica. Les bases també esmenten innovació, tecnologia, aprenentatge, usabilitat, presentació i utilitat. Les ponderacions anteriors són un instrument intern per decidir, no els pesos del jurat.
